# Turn-Based Adventure

A Java turn-based adventure game inspired by Slay the Spire.

## Project
CS3354 - Java OOP Project

## Development
Phase 1: Console-based application
Phase 2: Graphical user interface

## Requirements
- Java JDK 21

## Planned Features
- Three playable classes: Warrior, Rogue, Wizard
- Three stages with unique encounters and bosses
- Turn-based combat with abilities and resources
- Equipment, inventory, and skill enchantments
- Node-based exploration and character progression
